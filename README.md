# Minigame 1
## Devlog
Michael Cornett

A sports team could serve as a good metaphor for the relationship between Components, GameObjects, and Scenes. GameObjects would represent the players, the field, balls, etc. Components would represent the skillset/role of each player on the team. Lastly the Scene would represent the current match being played, with the players, the field, the ball, and their skills be isolated to that specific match being played.
